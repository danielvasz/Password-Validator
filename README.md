# Angular Password Validator - Proyecto Base

Este repositorio contiene un proyecto de Angular que implementa un sistema robusto de validación de contraseña en tiempo real. Utiliza Formularios Reactivos para la gestión del estado y la librería zxcvbn (de Dropbox) para la estimación de la fortaleza de la contraseña.

El objetivo es proporcionar feedback instantáneo al usuario, guiándolo a través de los requisitos de seguridad.
